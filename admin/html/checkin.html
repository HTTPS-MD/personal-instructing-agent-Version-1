Check-in

Start check-in for a section. Students type their student number and wait here. Tick only the students you can see in the lab, then let them in. Stop check-in when everyone is in: people already in keep going.

Student numbers

Paste one student per line as email, student number (11 digits). Existing numbers are replaced.

The tutoring closing time is a separate setting in the admin console. It is not changed here.
