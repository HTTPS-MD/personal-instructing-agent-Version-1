1

Measure before you teach

Students answer the 50-item Big Five inventory. Scoring runs server-side, so the profile that drives the session can't be edited from the browser.

2

Match a persona to the profile

One of six teaching personas is assigned from the result — or freely chosen, depending on which arm of the study the student is in.

3

Practise with a tutor that adapts

The agent works through Grade 7 algebra, changing how early a hint arrives and how quickly difficulty climbs after a streak.

4

Compare against the baseline

Every condition is measured against the same pre-test, so the difference the persona makes is the thing being measured.

Built as a research instrument

Every rule that matters is enforced by the database, not the interface.

Personality-first

The Big Five result is scored on the server and never reaches the student's browser — knowing your own score would change how you behave for the rest of the study.

Personas that differ

Each agent changes how a problem is scaffolded: when a hint arrives, how much encouragement carries it, how fast the difficulty climbs.

Clean data by design

Answers are checked server-side and hints are metered, so a session that shouldn't have counted simply cannot.
